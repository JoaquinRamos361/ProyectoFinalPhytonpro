ClimateBot

ClimateBot es un bot de Discord desarrollado en Python que tiene como objetivo compartir información sobre el cambio climático y el cuidado del medio ambiente.
A través de diferentes comandos, permite conocer datos interesantes, recibir consejos ecológicos y consultar información sobre la calidad del aire de distintas ciudades.

Funcionalidades:

!contaminacion <ciudad>
Consulta la calidad del aire de una ciudad.

!dato
Comparte un dato interesante sobre el cambio climático.

!consejo
Muestra un consejo para cuidar el medio ambiente.

!ayuda
Muestra los comandos disponibles del bot.

Tecnologías a utilizar:
Python: lenguaje utilizado para desarrollar el bot.
Discord.py: biblioteca para crear y conectar el bot con Discord.
APIs: para obtener información sobre la calidad del aire.
JSON: para guardar y organizar datos.

Como instalarlo:
Clonar el repositorio.
Crear un entorno virtual.
Instalar las bibliotecas necesarias.
Configurar el token del bot de Discord en el archivo .env.
Ejecutar el archivo main.py.

Objetivo del proyecto:
Este proyecto busca combinar la programación con el cuidado del medio ambiente, poniendo en práctica conocimientos de Python como clases, métodos, APIs, manejo de archivos y uso de bibliotecas externas.
Además, busca compartir información ambiental de una manera sencilla y accesible a través de Discord.
